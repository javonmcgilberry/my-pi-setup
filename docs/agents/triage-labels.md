# Triage labels

The engineering skills use five canonical roles. Local Markdown tickets record
the corresponding value in their `Status:` field.

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is required. |
| `ready-for-agent` | `ready-for-agent` | The ticket is fully specified for autonomous work. |
| `ready-for-human` | `ready-for-human` | Human implementation or action is required. |
| `wontfix` | `wontfix` | The work will not be pursued. |

Change only the local status column if this repository adopts different local
vocabulary later.
